# 処理順序

| 段階 | 出力 |
| --- | --- |
| 入力 | フレーム内で共有する入力状態 |
| 更新 | ゲームの確定状態 |
| 描画 | 更新後の状態を使った画面 |

## 入力処理

ボタンの押下、保持、解放を区別する。[確認手順](diagnostics.md#動作確認) でフレーム番号を照合できる。

## アセットの登録

読み込みが完了したアセットを、更新処理の前に登録する。

## 描画フレーム

更新が完了してから描画対象を選ぶ。

![入力、更新、描画の順に処理する図](diagrams/frame-flow.svg)

## 前提

描画対象から外れたオブジェクトも、ゲーム上必要な処理は更新する。同じ名前の見出しが [概要](frame-overview.md#前提) にもある。
